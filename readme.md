# 6組総当たり:最大待ちの回数が最小(5回)になる対戦順の4種類

## 前提

- 6組の固定ペアによる総当たり(全15試合)を、1面で1試合ずつ行う。
- 条件は次の3つ(「全試合消化する」にチェックを入れたときと同じ)。
  - 連続出場なし
  - 最大待ちは3試合以内
  - どの時点で打ち切っても、ペアごとの消化試合数の差は2以内
- この条件を満たす順番は全部で 324,720 通り。そのうち、3試合待ちの回数が最小の5回になるのは 2,880 通り。
- 2,880 通りを、ペアの番号を付け替えて同じになるものどうしでまとめると、**4種類**になる(各 720 通り = 6組の番号の付け替え方 6! 通り)。

## 表の見方

- ペアの番号は、どの種類も第1試合を `1-2`、第2試合を `3-4` とし、それ以降は初めて出てくる順に付け直している。
- **[ ]** 内は、その試合に「3試合待ったあとで出てくる」ペア。

## 4種類の関係

| 種類 | パターン | 3試合待ちが起きる試合 | 第10試合で出番を終えるペア | 完全な3試合(6組全員が1回ずつ出る連続3試合) |
|---|---|---|---|---|
| 1 | 1112 | 第4・6・8・10・12試合 | ペア1 | 2〜4、4〜6、6〜8、8〜10、10〜12 |
| 2 | 122 | 第4・6・8・10・12試合 | ペア1 | 2〜4、4〜6、6〜8、8〜10、10〜12 |
| 3 | 1112 | 第5・7・9・11・12試合 | ペア1 | 1〜3、3〜5、5〜7、7〜9、10〜12 |
| 4 | 1112 | 第5・7・9・11・12試合 | ペア3 | 1〜3、3〜5、5〜7、7〜9、10〜12 |

- 種類1と2は第10試合までまったく同じで、最後の5試合の並べ方だけが違う。
- 種類3と4は第4試合まで同じ。
- どの種類も、1組が第10試合で出番を終え、もう1組が第13試合で終える。
- どの種類も、逆順に並べ直すと最適ではなくなる(前半で1組が早めに出番を終える形が、最小化に欠かせないため)。
- パターン 122 は種類2だけで、残りの3種類は 1112。全 2,880 通りの内訳は「122 が 720 通り、1112 が 2,160 通り」。

## 補足:最小が5回になる理由(要約)

待ちを数え上げると、次の式が成り立つ。

> 3試合待ちの回数 = (6組の最終出場の試合番号の合計) − 71 − (完全な3試合の数)

- 第15試合の2組は15、第14試合の2組は14で出番を終える。第13試合には第14・15試合に出ない組が必ず1組いるので、その組は13で終える。
- 残る1組が出番を終える試合を x とすると、差2以内の条件から x ≥ 10。
- 完全な3試合は隣り合えず、始まりは第 x 試合以前なので、最大で「x÷2 の切り上げ」個。

したがって

> 3試合待ちの回数 = x −(完全な3試合の数)≥ x ÷ 2(切り捨て)≥ 5

等号は「1組が第10試合で出番を終え、第1〜10試合を始まりとする完全な3試合が、隣り合わずに5つある」ときに成り立つ。4種類はすべてこの形になっている(完全な3試合の位置は「2〜4、4〜6、…、10〜12」と「1〜3、3〜5、5〜7、7〜9、10〜12」の2通り)。

なお、差1以内(チェックなし)のときは、第1〜3、4〜6、7〜9、10〜12、13〜15試合が必ず完全な3試合になり、全組が第13試合以降で出番を終えるため、3試合待ちはどう組んでも 84 − 71 − 5 = 8回になる。
